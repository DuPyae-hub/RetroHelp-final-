# RetroHelp presentation

## Files

| File | What it does |
|------|----------------|
| `RetroHelp-Presentation.html` | Visual slide preview + **Download PowerPoint** button |

## Quick start

1. Double-click **`RetroHelp-Presentation.html`** (or open in Chrome / Edge).
2. Scroll to preview all **22 slides** (teal + orange theme).
3. Click **Download PowerPoint (.pptx)** — saves `RetroHelp-Presentation.pptx` to your Downloads folder.
4. Open the `.pptx` in Microsoft PowerPoint or Google Slides.
5. On slide 1, replace `[Your Name]` and `[Date]`.
6. Optional: add screenshots from your running app (Home, Find Clinic, Library, Profile).

## Present mode

- Click **Present (F)** or press **F**
- **→** or **Space** = next slide  
- **←** = previous slide  

## No internet?

Preview still works offline. The **Download** button needs internet once (loads PptxGenJS from CDN).

## Print to PDF

`Ctrl/Cmd + P` → Save as PDF (one slide per page if you use print CSS).
